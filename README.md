# Controle de Gastos

Esse é um projeto que fiz para praticar Python e aprender um pouco mais sobre desenvolvimento de aplicações.

A ideia foi criar um programa simples para cadastrar meus gastos e conseguir visualizar quanto já foi gasto.

## O que o programa faz

* Adiciona gastos
* Mostra os gastos cadastrados
* Edita gastos
* Exclui gastos
* Calcula o total
* Salva os dados em um arquivo JSON

## Tecnologias utilizadas

* Python
* Tkinter
* JSON

## O que estou praticando

Nesse projeto estou colocando em prática alguns conceitos que estou aprendendo em Python:

* Variáveis
* Listas
* Dicionários
* Funções
* `if` e `else`
* Laços de repetição
* `try` e `except`
* Arquivos
* JSON
* Interface gráfica com Tkinter

## Como executar

Com o Python instalado, execute:

```bash
python gastos.py
```
